Ankit Tiwari: Portfolio

My personal portfolio website, built with React and Vite. It shows my projects, skills, experience and education, and how to contact me.

Features
Responsive dark design that works on mobile and desktop
Typing animation for my roles in the hero section
Project cards with live demo and source code links
Skills grouped by area, plus an experience and education timeline
Smooth scroll animations (switched off automatically for people who prefer reduced motion)
Projects featured
Project	Stack	Links
Real-Time Group Chat	MongoDB, Express, React, Node.js	Live demo
GenUI (Prompt2UI)	React, AI APIs, JavaScript	Live demo
College Community Hub	React, Tailwind CSS, Python, MySQL	In progress
Notes App	JavaScript	Source
Express Task Manager	Express, Node.js	Source
CRUD User App	JavaScript	Source
Tech stack

React 18, Vite 5, plain CSS (custom properties, grid, animations).

Run locally

You need Node.js 18 or newer.

bash
git clone https://github.com/Ankit-tiwarii01/portfolio.git
cd portfolio
npm install
npm run dev

Open the local address shown in the terminal (usually http://localhost:5173).

Build for production
bash
npm run build
npm run preview

The production files are created in the dist/ folder.

Deploy

On Netlify or Vercel, import this repository and use:

Build command: npm run build
Publish directory: dist
Customise
Projects, skills, links and timeline: edit the data at the top of src/App.jsx
Colours and fonts: edit the variables at the top of src/index.css
Photo: replace public/photo.jpg
